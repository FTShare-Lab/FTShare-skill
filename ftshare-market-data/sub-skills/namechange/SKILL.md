# 查询 A 股股票曾用名

## 接口说明

| 项目     | 说明                                       |
|----------|--------------------------------------------|
| 接口名称 | 查询 A 股股票曾用名                         |
| 外部接口 | `/api/v1/market/data/namechange`           |
| 请求方式 | GET                                        |
| 适用场景 | 按股票代码查询该股票的历史曾用名及使用区间 |

## 请求参数

| 参数名      | 类型   | 是否必填 | 描述                                                | 取值示例     | 备注                                                                  |
|-------------|--------|----------|-----------------------------------------------------|--------------|-----------------------------------------------------------------------|
| trade_code  | string | 是       | 股票代码                                            | 600848.SH    | 带 .SZ/.SH 后缀，支持逗号分隔多个，如 `600848.SH,000001.SZ`           |
| start_date  | string | 否       | 过滤区间起始日期                                    | 20200101     | `YYYYMMDD` 格式；与 `end_date` 同时提供时须 `start_date` ≤ `end_date` |
| end_date    | string | 否       | 过滤区间结束日期                                    | 20241231     | `YYYYMMDD` 格式；与 `start_date` 同时提供时须 `start_date` ≤ `end_date` |

## 执行方式

通过根目录的 `run.py` 调用（推荐）：

```bash
python <RUN_PY> namechange --trade_code 600848.SH
python <RUN_PY> namechange --trade_code 600848.SH --start_date 20200101 --end_date 20241231
```

> `<RUN_PY>` 为主 `SKILL.md` 同级的 `run.py` 绝对路径。

## 响应结构

```json
[
    {
        "trade_code": "600848.SH",
        "name": "上海临港",
        "start_date": "20151118",
        "end_date": null
    },
    {
        "trade_code": "600848.SH",
        "name": "自仪股份",
        "start_date": "20070514",
        "end_date": "20151117"
    }
]
```

### 字段说明

| 字段名      | 类型   | 是否可为空 | 说明                                                                              |
|-------------|--------|------------|-----------------------------------------------------------------------------------|
| trade_code  | string | 否         | 股票代码（带 .SZ/.SH 后缀）                                                        |
| name        | string | 否         | 该时段内使用的股票名称                                                            |
| start_date  | string | 是         | 使用该名称的起始日期（`YYYYMMDD`；最早曾用名之前原名称可能为空字符串）             |
| end_date    | string | 是         | 使用该名称的结束日期（`YYYYMMDD`）；`null` 表示当前仍在使用                        |

## 注意事项

- `trade_code` 必填，为空时接口返回 400。
- 不分页，单只股票一次性返回全部历史名称记录；多 `trade_code`（逗号分隔）时合并返回。
- 日期参数格式为 `YYYYMMDD`，非时间戳。
