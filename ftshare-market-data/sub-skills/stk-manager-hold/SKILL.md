# 查询上市公司管理层持股变动明细

## 接口说明

| 项目     | 说明                                                |
|----------|-----------------------------------------------------|
| 接口名称 | 查询上市公司管理层人员持股变动明细                    |
| 外部接口 | `/api/v1/market/data/stk-manager-hold`              |
| 请求方式 | GET                                                 |
| 适用场景 | 查询上市公司管理层人员的持股变动明细，含持股数、变动原因 |

## 请求参数

| 参数名      | 类型   | 是否必填 | 描述                          | 取值示例     | 备注                                                       |
|-------------|--------|----------|-------------------------------|--------------|------------------------------------------------------------|
| trade_code  | string | 是       | 股票代码                      | 600848.SH    | 带 .SZ/.SH 后缀，支持逗号分隔多个，如 `600848.SH,000001.SZ` |
| end_date    | string | 否       | 截止日期，精确匹配            | 20241231     | `YYYYMMDD` 格式；不传则返回该股票全部历史记录               |

## 执行方式

通过根目录的 `run.py` 调用（推荐）：

```bash
python <RUN_PY> stk-manager-hold --trade_code 600848.SH
python <RUN_PY> stk-manager-hold --trade_code 600848.SH --end_date 20241231
python <RUN_PY> stk-manager-hold --trade_code 600848.SH,000001.SZ
```

> `<RUN_PY>` 为主 `SKILL.md` 同级的 `run.py` 绝对路径。

## 响应结构

```json
[
    {
        "trade_code": "000001.SZ",
        "end_date": "20251231",
        "name": "杨志群",
        "shares_num": "50000",
        "change_reason": ""
    }
]
```

### 字段说明

| 字段名          | 类型   | 是否可为空 | 说明                                                |
|-----------------|--------|------------|-----------------------------------------------------|
| trade_code      | string | 否         | 股票代码（带 .SZ/.SH 后缀）                          |
| end_date        | string | 否         | 截止日期（`YYYYMMDD`）                              |
| name            | string | 否         | 管理人员姓名                                        |
| shares_num      | string | 否         | 持股数（股），高精度数值，序列化为字符串             |
| change_reason   | string | 否         | 变动原因说明                                        |

## 注意事项

- `trade_code` 必填，为空时接口返回 400。
- 不分页，单只股票一次性返回全部持股记录；多 `trade_code`（逗号分隔）时合并返回。
- 排序：`trade_code` 升序、`end_date` 降序、`name` 升序。
- `shares_num` 为高精度数值，JSON 序列化为字符串以避免精度丢失。
- 日期参数格式为 `YYYYMMDD`，非时间戳。
